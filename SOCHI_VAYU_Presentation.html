4. Hexadecimal Protocol & Bit-Shift Decoding Engine
Protocol Engine
📡 Active Master Request-Response Handshake
Strict timing query loop every 1.5 seconds
  • Master Request Frame: 11 02 01 00 EC
    • 0x11: Frame Header | • 0x02: Payload Length | • 0x01: Read Results | • 0x00: Option | • 0xEC: Checksum
  • Response Packet Layout (14 to 26 Bytes):
    • Byte 0: 0x16 (Frame Sync Header)
    • Byte 1: Payload Byte Count (N)
    • Bytes 3-4: CO2 = (Byte 3 << 8) | Byte 4
    • Bytes 5-6: PM2.5 = (Byte 5 << 8) | Byte 6
    • Bytes 7-8: Temp = ((int16)(Byte 7 << 8) | Byte 8) / 10.0
    • Bytes 9-10: Hum = ((Byte 9 << 8) | Byte 10) / 10.0
    • Bytes 11-12: VOC = (Byte 11 << 8) | Byte 12
🛡️ Data Integrity & Zero-Simulation Guarantee
Fault-tolerant embedded processing
  • Mathematical Checksum Verification:
    CS = (256 - (Sum of Bytes[0..N-1] % 256)) & 0xFF
    Corrupted frames resulting from electrical noise are discarded instantly before touching the data model.
  • Watchdog Disconnection Timeout (3.5s): If sensor wires are detached, telemetry resets cleanly to 0, broadcasting "sensor":"DISCONNECTED".
  • No Synthetic Data Leak: Completely purged demo drift routines; dashboards represent 100% verified physical sensor hardware.
  • Circular Frame Buffer: Non-blocking state machine automatically resynchronizes on the 0x16 header byte.
